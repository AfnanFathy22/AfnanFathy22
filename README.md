The platform brings together different aspects of Egyptian heritage, including:

- Traditional folk dances.
- Egyptian jokes and storytelling.
- Traditional Egyptian cuisine.
- Interactive avatar to enhance user engagement.

#### 2. 👗 STYLO – AI-Powered Fashion Recommendation System

**Your Intelligent Fashion Assistant**

A collaborative AI-powered fashion platform combining Computer Vision, NLP, Machine Learning, and Generative AI to provide personalized fashion recommendations.

**Key Features:**

- Visual fashion search and similar-item recommendations.
- Complete outfit recommendations.
- AI-powered virtual try-on.
- Fashion image understanding.
- Customer review sentiment analysis.

**Technologies:** Python, PyTorch, Computer Vision, NLP, Deep Learning, Generative AI.

#### 3. 🧵 Shamsa – Arabic RAG Assistant for Egyptian Heritage

An Arabic Retrieval-Augmented Generation (RAG) chatbot designed to answer questions about Egyptian traditional crafts using documented knowledge sources.

**Key Features:**

- Retrieval-Augmented Generation for knowledge-grounded answers.
- Semantic search using BGE-M3 embeddings.
- Vector database integration using Qdrant.
- Reranking using BGE Reranker.
- AI-generated responses using Gemini.
- Animated interactive avatar with voice output.

**Technologies:** Python, RAG, BGE-M3, Qdrant, BGE Reranker, Gemini, Gradio, Edge TTS.

#### 4. ⚽ Football Analysis – Computer Vision

A computer vision system designed to analyze football matches and extract meaningful information from match videos.

**Key Features:**

- Object tracking.
- Team assignment.
- Camera movement estimation.
- Player speed estimation.
- Distance calculation and movement analysis.

**Technologies:** Python, YOLOv8, OpenCV, PyTorch.

- Interactive prediction application using Streamlit.
